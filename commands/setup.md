# /setup

Follow the windsor-get-started skill: check the sign-in with `get_current_user` (if it fails, tell the user to run `/mcp`, select `windsor-ai`, and sign in), summarise `get_connectors` by area, give a `get_connector_authorization_url` link for the first source they want, and finish with one first report for what is connected.
